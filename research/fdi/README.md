## Python causal model

`causal-design.json` is the current municipal specification. It supersedes the
unexecuted municipal implementation in the historical national configuration.
The active estimator is **Python ModernDiD 0.4.0**, Callaway–Sant’Anna doubly robust
group-time effects, with municipality bootstrap inference and simultaneous bands.
No R model ran. An unused legacy source is retained only to preserve the exact
completed national code identity; it is not an active analysis instruction.

The Facure handbook informs the DAG, nuisance-model reasoning and staggered
comparisons. A labeled known-effect estimator test recovered 1.8062 for a generated
effect of 1.8, with deterministic replay. That test is not a Brazil finding.

Actual municipal effects remain unavailable: the first-opening registry,
prior-exposure histories for treated and comparison municipalities, and harmonized
IBGE/RAIS outcomes have not been verified. A short list of plant histories cannot
identify never-treated municipalities. Do not replace that missing evidence with
synthetic data, a predictive model, or a zero effect.

## Monetary comparison extension

`scripts/fdi_temporal.py` independently prepares 6,510 annual rows with constant 2025 USD, population scaling, GDP shares and a complete-month IPCA/FX-adjusted BRL view for Brazil. The CPU Colab output was downloaded and independently SHA256/CRC/member-verified before use. US GDP deflator and Brazilian consumer-price adjustments answer different questions and are not PPP or capital-volume measures. See `temporal-methods.md`.
